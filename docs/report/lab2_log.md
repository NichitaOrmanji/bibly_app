# Журнал выполнения ЛР2 — статический UI приложения Bibly

Материал для отчёта: что делалось, в каком порядке, какие проблемы возникли
и как решены. Скриншоты лежат в `screenshots/`.

## Требования ЛР2 (кратко)

- Только статический UI: `StatelessWidget` везде (обёртка с `NavigationBar`
  может хранить лишь индекс вкладки).
- Mock-данные в `lib/data/mock_data.dart`, в каждом списке ≥ 6 реалистичных элементов.
- ≥ 2 переиспользуемых виджета в `lib/widgets/`.
- Цвета не хардкодятся — только через `Theme.of(context)`.
- Вход статический: без `Form` и валидации.
- Без `go_router` (ЛР3), без состояния (ЛР4), без бэкенда (ЛР5).
- Минимум один git-коммит на экран.

## Ход работы

### Шаг 1. Создание проекта
- `flutter create bibly_app`, структура `lib/screens`, `lib/utils`, `lib/models`, `lib/services`.
- Коммит: «Начальный проект: flutter create, базовая структура lib/ и тема».

### Шаг 2. Тема Material 3
- `lib/utils/app_theme.dart`: палитра из одного seed-цвета (`ColorScheme.fromSeed`,
  глубокий синий `#3949AB`), светлая и тёмная темы, переключение по системе
  (`ThemeMode.system`).
- `lib/utils/app_constants.dart`: отступы и скругления.
- Коммит: «Тема Material 3: seed-цвет домена, светлая/тёмная по системе».

### Шаг 3. Экран входа
- `lib/screens/login_screen.dart`: логотип, название, слоган, поля E-mail и Пароль
  (`TextField` без `Form`), «Забыли пароль?», кнопка «Войти», ссылка на регистрацию.
- Кнопка «Войти» только переходит на главный экран, без проверки данных.
- Виджет-тесты: экран содержит 2 поля и кнопку; нет переполнения на экране 320×568.
- Коммит: «Экран входа: статические поля e-mail/пароль и кнопка «Войти»».

### Шаг 4. Сборка под Android и запуск на эмуляторе (17.10.2026)
- Эмулятор `Bibly_Phone`: Android 11 (API 30), x86_64, Google APIs, 1.5 ГБ RAM —
  выбран лёгкий образ, т.к. ПК слабый (i5-5200U, 8 ГБ); образы API 37 не загружались.
- Проблема 1: сборка упала — `Android sdkmanager did not install NDK 28.2.13676358`.
  Flutter требует NDK (`ndkVersion = flutter.ndkVersion` в `android/app/build.gradle.kts`).
- Проблема 2: ручная установка `sdkmanager "ndk;28.2.13676358"` из PowerShell
  «успешно» завершалась, но ничего не ставила: `cmd` разбивает аргумент по `;`.
  Решение: вызов через `cmd /c` с экранированными кавычками — NDK установлен (2.1 ГБ).
- `flutter build apk --debug` — успешно (~7 минут, первая сборка Gradle).
- Установка: `adb install -r build/app/outputs/flutter-apk/app-debug.apk`, запуск приложения.
- Замечание: в логе ошибка Impeller `Could not link pipeline program` (OpenGL ES
  эмулятора), но экран отрисовался корректно.
- Скриншот: `screenshots/01_login_android.png` — экран входа на эмуляторе.

### Шаг 5. Экран «Мой день» и нижняя навигация
- Модели: `lib/models/verse.dart` (стих: текст + ссылка),
  `lib/models/daily_task.dart` (пункт плана: название, подпись, минуты, вид, выполнен ли).
- Mock-данные: `lib/data/mock_data.dart` — имя пользователя, дата, серия 12 дней,
  стих дня (Ин 3:16), план на сегодня из 7 пунктов (3 выполнены).
- Переиспользуемые виджеты в `lib/widgets/`:
  - `SectionHeader` — заголовок раздела с подписью справа («3 из 7»);
  - `VerseCard` — карточка стиха (пригодится для поиска);
  - `DailyTaskTile` — строка плана, иконка зависит от вида (чтение / молитва / размышление / аудио);
  - `ComingSoonView` — временная заглушка для ещё не сделанных вкладок.
- `lib/screens/my_day_screen.dart` (`StatelessWidget`): приветствие, дата, чип серии дней,
  стих дня, прогресс-бар плана, список пунктов. Все цвета — из `Theme.of(context).colorScheme`.
- `lib/screens/main_shell.dart`: `NavigationBar` на 4 вкладки (Мой день / Библия /
  Вместе / Скиния). Единственный `StatefulWidget` хранит только индекс вкладки;
  `IndexedStack` сохраняет прокрутку при переключении.
- Кнопка «Войти» теперь ведёт в `MainShell`; заглушка `home_screen.dart` удалена.
- Проверка: `flutter analyze` — без замечаний; 3 виджет-теста пройдены (переход с входа,
  отсутствие переполнения на экране 320×568, переключение вкладок).
- Повторная сборка APK — 36 с (против ~7 мин в первый раз).
- Скриншоты: `screenshots/02_my_day_android.png` (верх экрана),
  `screenshots/03_my_day_plan_android.png` (весь план после прокрутки).

### Шаг 12. Экран «Вместе»
- Модели `lib/models/community.dart`: `ReadingGroup` (название, участники, план, прогресс)
  и `FriendActivity` (кто, что сделал, когда, текст записи, которой поделились,
  число «Помолюсь»).
- Mock-данные: 6 групп совместного чтения и 7 событий ленты: прогресс в плане,
  общие (не приватные) записи дневника, просьбы о молитве.
- `lib/screens/together_screen.dart`:
  - «Мои группы» — горизонтальный `ListView.separated` с карточками групп
    (название, план, `LinearProgressIndicator`, участники, процент);
  - «Лента друзей» — карточки событий с аватаром `InitialsAvatar` (общий виджет с
    «Профилем»), текстом и кнопкой «Помолюсь · N».
- Вкладка-заглушка больше не нужна: виджет `ComingSoonView` удалён.
- Проблема: на узком экране (тест 320×568) нижняя строка карточки переполнялась на
  105 px (жёлто-чёрная полоса). Причина — `Row` с текстом времени и кнопкой без
  ограничения ширины. Решение — обернуть текст времени в `Expanded` с
  `TextOverflow.ellipsis`.
- Проверка: `flutter analyze` — без замечаний; 9 тестов пройдены.
- Скриншоты: `screenshots/15_together_android.png`, `screenshots/16_together_feed_android.png`.

### Шаг 13. Экран «Поиск»
- Открывается кнопкой-лупой в AppBar «Моего дня» и «Библии» (`Navigator.push`).
- Mock-данные: запрос «любовь», 6 недавних запросов, 7 найденных стихов

- `lib/screens/search_screen.dart`:

  - фильтры «Все / Ветхий Завет / Новый Завет / Мой дневник» — `FilterChip` в
    горизонтальном `ListView.separated` (работать начнут в ЛР4);
  - недавние запросы — `ActionChip` в `Wrap`;
  - результаты — `ListView.separated` с переиспользуемым виджетом `VerseCard`
    (тот же, что «Стих дня» в «Моём дне»).
- Тело экрана — `Column`, а список результатов в `Expanded`, поэтому на маленьком
  экране прокручивается только список, и переполнения нет.
- Проверка: `flutter analyze` — без замечаний; 10 тестов пройдены.
